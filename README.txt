Yogesh Jatale portfolio
=======================

Open index.html in a browser to preview. No build step, no external requests
(fonts and photo are bundled), so it also works on GitHub Pages or any static host.

Files
  index.html              the page
  assets/css/site.css     all styles (dark and light themes)
  assets/js/site.js       theme button, mobile menu, resume button
  assets/img/             your photo (webp + jpg), favicon
  assets/fonts/           Bricolage Grotesque and Newsreader (self-hosted)

Your old portfolio.html, portfolio.css and app.js are untouched. Copy these new
files next to them; index.html becomes the home page.

Add your resume
  Save the PDF as assets/Yogesh_Jatale_Resume.pdf. The "Download resume"
  buttons appear automatically once the file is on a web server.

Edit content
  All text is plain HTML in index.html. Search for the project name to change it.

Do NOT commit ojpms_new/ to GitHub: EmailUtil.java and persistence.xml in it
contain a Gmail app password and a database password.
